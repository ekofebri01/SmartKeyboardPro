# Smart Keyboard Pro

A fast, lightweight, and modern open-source Android virtual keyboard built with Kotlin and Jetpack Compose. Designed for maximum typing efficiency, low resource usage, and clean Material 3 design.

## Features

- **Lightning-Fast & Lightweight**: Optimized codebase with a minimal APK footprint (< 10MB) and zero bloat.
- **Smart Auto-Text & Shortcuts**: Expand abbreviations instantly (e.g. `omw` -> `On my way!`) with zero latency.
- **Local Predictive Text & Dictionary**: Offline word prediction and learning capabilities supporting Indonesian and English dictionaries.
- **Customizable Themes & Key Height**: Choose from classic themes or build your own custom color palette and key dimensions.
- **Universal Backup & Restore**: Export and import your settings, dictionary words, and auto-text shortcuts via `.json`, `.zip`, or `.db` files.
- **Privacy First**: 100% offline-capable with no telemetry, tracking, or network permissions required for core typing.

## Building from Source

To build the APK locally using Gradle:

```bash
gradle assembleDebug
```
